# Bilingual creation and asset workspace

Request: improve the browser editor and original canvas, make characters/assets useful and visually readable, and adapt Toonflow prompt/template patterns for English and Mandarin. Preserve platform-owned model choice, explicit credit quotation, original Storyboard and existing media ownership controls.

Design: a compact editor header with secondary tools separated from export; readable asset/tool panels. Canvas nodes show entity kind, useful detail and visual references only when authenticated media is available, with consistent larger geometry. Character and scene detail panels become editable instead of read-only. A reusable prompt workbench supports English/Simplified Chinese versions, category selection, named variables, editable template text, rendered preview and project-owned saved templates. Using a template is free; only the existing quote/confirm action initiates generation. Prompt language is explicit and independent from provider/model choice.

Template sources: inspect pinned Toonflow source and licences before incorporating text. Retain notices and source provenance. Use safe, self-contained prompt blocks rather than copying an entire agent/tool protocol. Variable placeholders are rendered as text; no eval, HTML rendering or arbitrary fetch. Context injection uses selected project's saved character/scene descriptions, not an implied image-conditioning capability. User-authored overrides remain user messages; platform system constraints remain fixed.

Persistence: project-owned bilingual templates in PostgreSQL, bounded validated JSON fields, revision-protected updates and owner checks. No provider credentials or model fields. Save both language versions with visible missing-version state. Built-ins cannot be overwritten; saving creates a user copy. Custom text remains editable after applying. Snapshot the final rendered prompt in the existing generation quote.

Implementation: (1) inspect reference and current canvas/editor; (2) implement project template API and meaningful ownership/CAS tests; (3) bilingual catalogue/rendering and prompt workbench; (4) character/scene editing and richer canvas nodes, wire workbench to story and entity fields; (5) editor hierarchy/asset panel refinement; (6) type/build/backend tests and one desktop/mobile browser review; (7) update provenance/operations, publish both split repos and refresh preview. AWS/live payment activation remains out of scope.

Implemented catalogue: six paired templates (character design sheet, scene/environment, prop/object, storyboard frame, continuous video direction and story outline). Character/scene/prop Chinese text is adapted from pinned Toonflow blocks; English is a 6eek translation. Storyboard/video are adapted content patterns without unsupported reference markers; story outline is original. Source and complete MIT notice are available in the interface. EN/中文 template editing changes the selected language only; custom user text is never silently translated. Project starters also have authored Mandarin versions and editable script/scene directions before import.
